# Elzzaim Telecom — متجر إلكتروني

موقع محل **Elzzaim Telecom** (غرداية): متجر إكسسوارات بالعربية والفرنسية، طلب بالدفع عند الاستلام أو عبر واتساب، خدمات التصليح والفليكسي، ولوحة تحكم.

- الموقع: `/`
- لوحة التحكم: `/admin`

## التشغيل
متغيرات البيئة: `DATABASE_URL` (Postgres/Neon)، `ADMIN_PASSWORD` (كلمة السر الأولى للوحة)، `SESSION_SECRET`.

```
npm install
npm start
```
الجداول تُنشأ تلقائياً عند أول تشغيل.
